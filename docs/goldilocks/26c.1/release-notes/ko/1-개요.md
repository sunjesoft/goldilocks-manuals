# 1. 개요

> 원본: [GOLDILOCKS 26c Release Note](https://manual.sunjesoft.co.kr/goldilocks/26c_1/release_note/b31b3585e7386d16)  

[전체 목차](README.md) · [2. 기능 추가 및 개선 →](2-기능-추가-및-개선.md)

이 장에서는 GOLDILOCKS 26c.1에서 추가되거나 변경된 기능을 설명한다. 기능 추가 및 개선 사항은 제품 영역별로 설명하고, 기존 환경에 영향을 미치는 지원 범위·설정·구문 변경 사항은 호환성 및 운영 변경 절에서 정리한다.

각 항목에는 변경 내용을 이해하고 사용하는 데 필요한 User Manual의 설명과 참조 링크를 함께 제공한다.

<a id="94eca92541c70700"></a>
| 영역 | 주요 내용 |
| --- | --- |
| 데이터베이스 관리 | 병렬 백업·복원·복구, 정보 조회 뷰, 서버 프로퍼티 변경 |
| SQL 및 PSM | Role, 제약 조건, 통계 정보, 집계·JSON·정규 표현식, MERGE, External Routine, Trigger |
| API | ODBC·JDBC·Embedded SQL 변경, PyDBC 기능 및 데이터 타입 처리, 프레임워크 지원 |
| Utility | gsql DDL 출력, gloader APPEND INSERT, gdump·glocator·gagent 변경 |
| Replication | CYCLONE의 다른 DBMS 연동 및 Heartbeat protocol 분리 |
